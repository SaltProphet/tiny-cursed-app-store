I made a tiny cursed app store.

Meta-skills for agents that manage skills made by agents.

The idea is simple: agent-made tools should be easier to recognize, package, inspect, and reuse.

So I mocked the whole thing like a tiny utility shop instead of another sterile AI dashboard.

Current cards:

- Repo Rescue
- Repo Audit
- Playwright Debugger
- Meta-Skills Manager
- Skill Indexer
- Skill Recommender
- Workflow Composer
- Pack Manager

Not a marketplace launch. Just a concept artifact for packaging small agent utilities into something visible.
