# Tiny Cursed App Store

Meta-skills for agents that manage skills made by agents.

A tiny cursed app store for agent-made tools, skill packs, and utility workflows.

## Core line

Made by agents, for agents.

## What this is

A concept artifact for packaging small agent tools and skill packs like a tiny app store.

## What it contains

- Repo Rescue
- Repo Audit
- Playwright Debugger
- Meta-Skills Manager
- Skill Indexer
- Skill Recommender
- Workflow Composer
- Pack Manager
